# 🗺️ ROADMAP

# Pyramide du Gang

Version : 1.0

Ce document décrit les grandes étapes du développement du projet.

---

# ✅ Phase 1 - Prototype

Objectif :

Valider les règles du jeu.

## Fonctionnalités

- Distribution des cartes
- Construction de la pyramide
- Révélation des cartes
- Tour des joueurs
- Bluff
- Contestation
- Compteur de gorgées

Statut :

✅ Terminé

---

# 🚧 Phase 2 - Game Engine V2

Objectif :

Créer un moteur de jeu indépendant de l'interface.

## Fonctionnalités

- Nouveau GameState
- GameEngine
- Dispatch des actions
- Gestion des règles
- Architecture modulaire
- Tests unitaires

Statut :

🚧 En cours

---

# ⏳ Phase 3 - Interface

Objectif :

Brancher l'interface sur le nouveau moteur.

## Fonctionnalités

- Suppression de l'ancien moteur
- Nouveaux composants React
- Historique des actions
- Amélioration de l'affichage
- Optimisation des performances

Statut :

⏳ À venir

---

# ⏳ Phase 4 - Expérience utilisateur

Objectif :

Rendre le jeu agréable à utiliser.

## Fonctionnalités

- Animations
- Sons
- Transitions
- Responsive
- Accessibilité

Statut :

⏳ À venir

---

# ⏳ Phase 5 - Multijoueur

Objectif :

Permettre à chaque joueur d'utiliser son téléphone.

## Fonctionnalités

- Création d'une partie
- Code de partie
- Lobby
- Synchronisation en temps réel
- Reconnexion
- Gestion des déconnexions

Statut :

⏳ À venir

---

# ⏳ Phase 6 - Progressive Web App

Objectif :

Installer le jeu comme une application.

## Fonctionnalités

- Installation mobile
- Mode hors ligne
- Icône
- Splash screen
- Mise à jour automatique

Statut :

⏳ À venir

---

# ⏳ Phase 7 - Statistiques

Objectif :

Ajouter de la progression.

## Fonctionnalités

- Historique des parties
- Classements
- Succès
- Statistiques
- Temps de jeu

Statut :

⏳ À venir

---

# 💡 Idées futures

Ces fonctionnalités ne sont pas prévues immédiatement mais pourront être ajoutées :

- Mode équipe
- Variantes de règles
- Jokers
- Cartes spéciales
- IA
- Mode spectateur
- Replays
- Tournois

---

# 🎯 Objectif final

Créer un jeu de soirée moderne, simple à utiliser et agréable à jouer, aussi bien en local qu'en ligne.

Le moteur devra être suffisamment robuste pour permettre l'ajout de nouvelles fonctionnalités sans remettre en cause l'architecture existante.
